## 🏗️ Featured Projects

### 1. [Scandine](https://github.com/mishra0703/scandine)

[![Next.js](https://img.shields.io/badge/Next.js-000000?style=flat&logo=nextdotjs&logoColor=white)](https://nextjs.org)  [![MongoDB](https://img.shields.io/badge/MongoDB-47A248?style=flat&logo=mongodb&logoColor=white)](https://mongodb.com)  [![Razorpay](https://img.shields.io/badge/Razorpay-02042B?style=flat&logo=razorpay&logoColor=3395FF)](https://razorpay.com)  [![Tailwind CSS](https://img.shields.io/badge/Tailwind_CSS-38B2AC?style=flat&logo=tailwind-css&logoColor=white)](https://tailwindcss.com)  [![React](https://img.shields.io/badge/React-20232A?style=flat&logo=react&logoColor=61DAFB)](https://react.dev)

**QR-based digital menu and ordering system** — customers scan a table QR code, browse the menu, and place orders directly from their browser. No app install, no waiting in line.

**Key highlights:**
- Unified full-stack codebase using Next.js API routes, eliminating the need for a separate backend server
- Integrated Razorpay for seamless in-browser payment collection at the table
- Secure admin panel with bcrypt-hashed credentials for menu and order management
- Designed with a mobile-first UI using Tailwind CSS — optimized for the real use case of a phone screen at a restaurant table

### 2. [Get Me a PS5](https://github.com/mishra0703/get-me-a-ps5)

[![Next.js](https://img.shields.io/badge/Next.js-000000?style=flat&logo=nextdotjs&logoColor=white)](https://nextjs.org)  [![MongoDB](https://img.shields.io/badge/MongoDB-47A248?style=flat&logo=mongodb&logoColor=white)](https://mongodb.com)  [![Razorpay](https://img.shields.io/badge/Razorpay-02042B?style=flat&logo=razorpay&logoColor=3395FF)](https://razorpay.com)  [![Tailwind CSS](https://img.shields.io/badge/Tailwind_CSS-38B2AC?style=flat&logo=tailwind-css&logoColor=white)](https://tailwindcss.com)  [![React](https://img.shields.io/badge/React-20232A?style=flat&logo=react&logoColor=61DAFB)](https://react.dev)

**Creator-focused crowdfunding platform** — users sign up, build a public profile, plug in their own Razorpay credentials, and start accepting donations from supporters.

**Key highlights:**
- Multi-tenant payment architecture — each creator connects their own Razorpay account, keeping funds independent and secure
- Customizable public profile pages, giving creators a personal fundraising page out of the box
- Built authentication and session management using NextAuth with OAuth provider support
- End-to-end full-stack implementation: auth, database, payments, and UI — all within a single Next.js codebase
